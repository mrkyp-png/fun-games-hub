2026-10-15 / 사용자 확정 기준 V 1092 G

1. 실제 노래의 박자·강박·구간 분위기를 분석하여 채보를 만든다. 일정 간격의 랜덤 노트만으로 대체하지 않는다.
2. 신나는 구간에는 음악에 맞는 두 버튼 동시 입력과 반복 패턴을 넣는다. 잔잔한 구간과 강한 구간의 노트 밀도를 구분한다. 모든 곡에 같은 패턴을 복사하지 않는다.
3. EASY / NORMAL / HARD를 각각 구성한다. 같은 칸에 캐릭터가 겹치지 않도록 최소 간격을 확보한다. 현재 곡 기준 간격은 EASY 2.22초 / NORMAL 1.88초 / HARD 1.65초이다. 다음 곡에도 캐릭터 접근 시간과 판정 여유를 확인한다.
4. 채보는 시간과 버튼 위치가 고정되어 다시 시작해도 동일하게 재생되어야 한다. 동시 노트는 각각 독립 판정한다. 기존 A의 판정·점수 규칙을 유지한다.
5. 원본 음악 파일을 보존한다. 게임용 파일을 별도로 만들고 곡 선택 목록에 추가한다. 기존 곡·기록·디자인을 임의로 덮어쓰지 않는다.
6. 음악 전체를 계속 재생하고 성공 입력에 짧은 타격 피드백을 준다. 실패 시 음악을 끄는 것만으로 리듬감을 대신하지 않는다.
7. 테스트 모드는 기본 켜짐: 미스가 많아도 곡 끝까지 진행하며 최고점 저장에서 제외한다. V1143 G부터 일반 모드도 MISS 횟수와 관계없이 곡 끝까지 진행한다. 테스트 모드는 최고점 저장에서 제외하는 구분만 유지한다.
8. 검증: 세 난이도 전체 채보, 박자 시각, 동일 칸 간격, 2버튼 실제 동시 터치, 개별 판정·점수, 일시정지·재개·종료, 곡별 기록, 테스트 기록 제외, A타입 회귀, 화면·성능을 확인한다. 브라우저 테스트 봇을 동시에 여러 개 실행하지 않는다.
9. 자동 분석은 1차 채보이다. 직접 듣지 않은 후렴을 청취 확인했다고 말하지 않는다. 사용자 실제 플레이 의견으로 박자가 어색한 구간과 난이도를 다듬는다.
10. 제작 순서: 원본 확인 → 음악 분석 → 박자 추적·구간 후보 → 난이도별 고정 채보 → 곡 목록 연결 → 자동/화면 검증 → 사용자 테스트 → 필요한 구간 보정.
