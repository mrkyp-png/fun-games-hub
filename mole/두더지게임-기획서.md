# 🦫 두더지 게임 기획서 v1.0

## 1. 게임 개요

### 게임명

두더지 게임

### 핵심 콘셉트

Emoji 그림을 여러 영역으로 나누고, 각 영역에 출현하는 두더지를 뿅망치로 잡아 모든 영역을 완성하는 게임.

### 핵심 게임 루프

Emoji 그림 등장
→ 영역별 두더지 출현
→ 두더지 터치
→ 뿅망치 타격
→ 두더지 제거
→ 해당 영역 완성
→ 모든 영역 완성
→ Emoji 그림 완성
→ CLEAR 및 보상

---

## 2. 게임 목표

플레이어는 제한시간 내에 모든 영역에서 두더지를 잡아 Emoji 그림을 완성해야 한다.

각 영역은 두더지를 1회 성공하면 완성된다.

최종적으로 모든 영역이 완성되면 스테이지 클리어.

---

## 3. Emoji 영역 시스템

Emoji 그림은 단계별로 서로 다른 수의 영역으로 구성한다.

1단계는 9개 영역에서 시작한다.

10단계는 18개 영역으로 구성한다.

| 단계 | 영역 수 |
| -- | ---: |
| 1  |    9 |
| 2  |   10 |
| 3  |   11 |
| 4  |   12 |
| 5  |   13 |
| 6  |   14 |
| 7  |   15 |
| 8  |   16 |
| 9  |   17 |
| 10 |   18 |

영역은 Emoji 이미지의 실제 형태에 맞춰 구성한다.

영역 크기가 서로 달라도 게임이 가능하도록 설계한다.

### 영역 크기별 출현 포인트

* 작은 영역: 1개
* 중간 영역: 1~2개
* 큰 영역: 2~3개

출현 포인트는 영역 내부에 배치한다.

---

## 4. 두더지 출현

두더지는 해당 영역 내부에서 출현한다.

두더지는 일정 시간 동안 화면에 존재하며, 플레이어가 터치하면 성공 처리한다.

두더지는 영역 밖에서 출현하지 않는다.

### 중첩 방지

두더지끼리 서로 겹치면 안 된다.

또한 다음 객체의 터치 판정 영역도 서로 겹치지 않도록 한다.

* 두더지
* 다른 동물
* 폭탄

배치 가능한 공간이 부족하면 강제로 겹치지 않고 실제 동시 출현 수를 줄인다.

---

## 5. 두더지 터치 방식

두더지 전체 영역이 터치 판정 영역이다.

머리, 몸통 등 특정 부위를 정확하게 터치할 필요가 없다.

플레이어가 두더지를 터치하면 터치 위치에 뿅망치가 나타난다.

### 뿅망치 연출

터치
→ 뿅망치 등장
→ 위로 올라감
→ 아래로 내려침
→ "뿅!" 타격 효과
→ 두더지 제거

뿅망치는 화면에 고정된 버튼이 아니다.

플레이어가 터치한 위치에 순간적으로 나타나는 시각적 효과다.

뿅망치의 실제 판정은 필요하지 않다.

실제 판정은 두더지 터치 영역으로 처리한다.

---

## 6. 두더지 출현시간

단계가 올라갈수록 두더지 유지시간을 감소시킨다.

| 단계 | 유지시간 |
| -- | ---: |
| 1  | 2.5초 |
| 2  | 2.4초 |
| 3  | 2.3초 |
| 4  | 2.2초 |
| 5  | 2.0초 |
| 6  | 1.8초 |
| 7  | 1.6초 |
| 8  | 1.4초 |
| 9  | 1.2초 |

두더지 사이에는 약 0.2~0.5초의 짧은 출현 간격을 적용한다.

각 두더지는 개별적으로 출현 및 퇴장한다.

| 1  |        1 |
| 2  |        1 |
| 3  |        2 |
| 4  |        2 |
| 5  |        3 |
| 6  |        3 |
| 7  |        4 |
| 8  |        4 |

동시 출현 수는 최대값이다.

영역 크기나 현재 배치 상황 때문에 안전한 배치가 불가능하면 실제 출현 수를 자동으로 줄인다.

---

## 8. 방해물

방해물은 두 종류다.

### 🐹 다른 동물

두더지와 유사한 방식으로 출현한다.

터치하면:

* 목숨 -1
* 콤보 초기화
* 해당 영역 진행 없음

### 💣 폭탄

터치하면:

* 제한시간 -3초
* 콤보 초기화
* 해당 영역 진행 없음
* 폭발 연출

## 11. 목숨

기본 목숨은 3개다.

### 목숨 변화

두더지 성공:

* 목숨 변화 없음

다른 동물 터치:

* ❤️ -1

폭탄:

* 목숨 변화 없음
* 시간 -3초

목숨이 0이 되면 실패한다.

---

## 12. 콤보

두더지를 연속으로 성공시키면 콤보가 증가한다.

| 콤보   |   점수 |
| ---- | ---: |
| 1    | +100 |
| 2    | +120 |
| 3    | +140 |
| 4    | +160 |
| 5 이상 | +200 |

5콤보 이상은 MAX COMBO 상태로 표시한다.

다른 동물 또는 폭탄을 터치하면 콤보를 0으로 초기화한다.

---

## 13. 영역 완성

두더지 성공 시 해당 영역이 즉시 완성된다.

연출:

두더지
→ 뿅망치
→ 타격
→ 두더지 제거
→ 해당 영역 이미지/색상 표시
→ 영역 완성 효과

완성된 영역은 다시 플레이 대상이 되지 않는다.

---

## 14. Emoji 완성

마지막 미완성 영역까지 성공하면 전체 Emoji 이미지가 완성된다.

최종 영역 성공 후 일반 영역 성공보다 강한 완성 연출을 적용한다.

연출:

마지막 두더지 성공
→ 뿅망치
→ 마지막 영역 완성
→ 전체 Emoji 완성
→ 반짝임/완성 효과
→ CLEAR 화면

---

## 15. 클리어 보상

클리어 시 다음 보상을 제공한다.

* ⭐ 별
* 🪙 코인
* 🖼️ 완성 Emoji 컬렉션 등록

별은 클리어 성적에 따라 1~3개를 지급한다.

---

## 16. 게임 난이도 상승 구조

두더지 게임의 난이도는 다음 요소를 동시에 상승시킨다.

1. 영역 수 증가
2. 동시 두더지 증가
3. 두더지 유지시간 감소
4. 방해물 증가
5. 방해물 종류 증가
6. 제한시간 감소

1단계는 게임 규칙을 익히는 단계로 구성하고,
10단계는 빠른 반응속도와 정확한 판단을 요구하는 고난도 단계로 구성한다.

---

## 17. 최종 게임 정체성

두더지 게임은 단순한 두더지 잡기가 아니라,

**"뿅망치로 두더지를 잡아 Emoji 그림을 완성하는 게임"**

을 핵심 정체성으로 한다.

어린이부터 성인까지 직관적으로 이해할 수 있어야 하며,
게임 조작은 단순하게 유지하고 난이도는 출현 패턴과 속도로 높인다.
