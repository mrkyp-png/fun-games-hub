# 🦫 두더지 게임 기획서 v1.0

## 1. 게임 개요

### 게임명

두더지 게임

### 핵심 콘셉트

Emoji 그림을 여러 영역으로 나누고, 각 영역에 출현하는 두더지를 뿅망치로 잡아 모든 영역을 완성하는 게임.

### 핵심 게임 루프

Emoji 그림 등장
→ 영역별 두더지 출현
→ 두더지 뜬 열의 레인 버튼 누름
→ 망치가 대각선으로 그 열 강타
→ 두더지 제거
→ 해당 영역 완성
→ 모든 영역 완성
→ Emoji 그림 완성
→ CLEAR 및 보상

---

## 2. 게임 목표

플레이어는 제한시간 내에 모든 영역에서 두더지를 잡아 Emoji 그림을 완성해야 한다.

각 영역은 두더지를 1회 성공하면 완성된다.

최종적으로 모든 영역이 완성되면 스테이지 클리어.

---

## 3. Emoji 영역 시스템

**v1.3 (사용자 확정): 전 레벨 4×4 = 16칸 고정 격자.** 레벨별 영역 수 증가표와
이미지 형태를 따라가는 분할(k-means)은 폐기.

* 16칸, 칸당 구멍 1개, 두더지 출현 포인트 1개(칸 중앙)
* 격자는 세로로 위 18% ~ 아래 85% 범위에 배치 (윗줄 두더지 머리 공간 확보)
* **배경 이모지는 칸별로 뚫지 않는다.** 전체가 90% 어두운 실루엣에서 시작해,
  두더지를 한 칸 잡을 때마다 실루엣이 **5%씩 통째로 옅어진다** → 16칸 다 잡으면
  0.90 − 16×0.05 = 0.10, 그림이 거의 다 드러난다. (`region-reveal.js`)
* 구멍은 레벨 시작 시 16개가 격자로 상시 배치되고 게임 끝까지 유지 (§5 참조)

---

## 4. 두더지 출현

두더지는 해당 영역 내부에서 출현한다.

두더지는 일정 시간 동안 화면에 존재하며, 플레이어가 그 열의 레인 버튼을 누르면 성공 처리한다 (§5).

두더지는 영역 밖에서 출현하지 않는다.

### 중첩 방지

두더지끼리 서로 겹치면 안 된다.

열 강타는 위치와 무관하므로 터치 판정 겹침 문제는 없다. 스폰 지점만 서로 겹치지 않으면 된다.

배치 가능한 공간이 부족하면 강제로 겹치지 않고 실제 동시 출현 수를 줄인다.

---

## 5. 조작 — 레인 버튼 + 대각 망치 (v1.4, 사용자 확정)

두더지를 직접 터치하지 않는다. 화면 하단의 **레인 버튼 4개**로 조작한다.
각 버튼은 4×4 격자의 한 **열**에 대응한다 (1번 버튼 = 1번 열).

버튼을 누르면:

→ 망치가 우측 하단 축에서 그 열로 대각선 스윙
  (이동 시간은 스윙 예비동작 안에 숨겨 체감 지연 ≈ 0)
→ 망치머리가 그 열 두더지의 **모자 정수리**에 착지
→ "쾅!" 타격 연출 (모자 정수리 기준: 히트스톱 · 화면 쉐이크 · 모자 튕김 ·
   별 · 흙먼지 · 진동 · 타격음)
→ 그 **열 전체** 판정 (아래 표)

| 열에 있던 대상 | 결과 |
|---|---|
| 두더지 (1히트) | 처치 — 영역 완성 + 콤보 + 점수 |
| 두더지 (다타, 미완) | 한 단계 내려감 (영역/콤보/점수 없음) |
| 두더지 (다타, 최종타) | 처치 |
| 다른 동물 (일반 얼굴) | 목숨 -1, 콤보 0 |
| 고글 낀 동물 | 시간 -3초, 콤보 0 |

* 한 번에 두더지 2마리를 잡으면 콤보가 2 오른다.
* **동물이 있는 열을 치면 손해.** 레인을 보고 눌러야 한다.
* 빈 열을 누르면 헛스윙만. 페널티도 잠금도 없다.
* 다타 두더지 연타 쿨다운(0.12초)은 열 강타에도 적용된다.

### 버튼 표시

* 그 열에 **두더지**가 떠 있으면 버튼이 은은하게 빛난다 (초보 가이드).
* **동물 / 고글 동물**은 버튼을 빛나게 하지 않는다 — 직접 격자를 보고 피해야 한다.

### 입력

* 모바일: 버튼 탭.
* PC: 버튼 클릭 + 키보드 `1` `2` `3` `4`.

### 아트 / 애니메이션 (v1.3, 사용자 확정)

이모지 글리프 대신 실제 스프라이트를 쓴다 (`assets/moles/`, `assets/hammer.png` —
`scripts/slice-mole-sprites.py` 가 원본에서 생성). 이전 버전은 두더지를 🦫 로 그렸는데
그 글리프가 없는 기기에서 □(빈 네모)로 떠서 교체함.

두더지 그림은 **흙두둑 없이 두더지 몸통만** 있는 시트(`두더지만.png`)를 쓴다. 흙두둑은
구멍 레이어가 담당하고, 두더지만 구멍에서 위아래로 움직인다. slice 스크립트가:
- **헬멧 넓이(가장 큰 빨간 덩어리)로 스케일 정규화** — 기준은 **안경 쓴 두더지(mole7)** 크기 (사용자 지정)
- 모든 프레임의 **"내용 아래끝(발치)"을 같은 캔버스 바닥에 맞춤** → 게임이 이 바닥을 구멍 입구에
  놓으므로 어떤 포즈든 발치가 구멍에 박히고, 키 큰 포즈는 머리가 더 위로, 빠끔은 턱만 나옴
- **흰 스티커 테두리 제거** (`defringe`: 알파 2px erode + 남은 near-white 가장자리 픽셀 삭제)

전신은 8종 (파란 모자 + 팔벌린 포즈는 크기가 튀어서 제외).

**깊이 사다리** — 두더지는 5단계 깊이를 가진다. 프레임 교체가 "숨는" 연출의 대부분을 하고,
translateY 는 내려가는 움직임만 살짝 더한다:

| 깊이 | 그림 | translateY (프레임 높이 대비) |
| -- | -- | -- |
| 0 | 전신 (mole1~8 무작위) | 0 |
| 1 | 빠끔 (눈, `peek1`) | 6% |
| 2 | 빠끔 (눈감음, `peek2`) | 11% |
| 3 | 모자만 (`helmet`) | 15% |
| 4 | 사라짐 | 120% (클립 밖) |

* `.mole-pop` 은 구멍 위 overflow:hidden 클립박스, 아래 끝이 구멍 입구 — translateY 로 내려간 두더지는 잘려서 "구멍 속으로" 사라진다
* 등장: 깊이 4 → 대기 깊이 로 역순 애니 (구멍에서 쑥 올라옴), ~55ms/칸
* 최종 타격 / 시간 초과: 깊이 4 로 내려가며 사라짐

**다타(多打) 두더지** — 출현 시 굴림 한 번으로 종류 결정 (전 레벨 고정):

| 종류 | 확률 | 대기 깊이 (타격 횟수별) |
| -- | --: | -- |
| 단타 | 80% | 0 |
| 2히트 | 15% | 0 → (타격) → 2 |
| 3히트 | 5% | 0 → 1 → 2 |

* 콤보 / 점수 / 영역 완성은 **최종 타격에서만** 처리 (중간 타격은 뽕망치 연출뿐)
* 같은 두더지 히트 간 0.12초 쿨다운 (연타 방지)
* 유지시간 배율: 2히트 ×1.7, 3히트 ×2.4 (후반 레벨에서도 잡을 시간 확보)

### 구멍 (§3 보강)

레벨 시작 시 4×4 격자로 구멍 그림(`hole`) 16개를 깔고 **게임이 끝날 때까지 그대로
유지한다** (칸을 완성해도 사라지지 않음 — 사용자 확정). 구멍 그림은 흙두둑 포함본
(`두더지.png`)에서 뽑는다.

## 8. 방해물

방해물은 두 종류다. **v1.3 (사용자 확정): 이모지 대신 `동물들.png`의 헬멧 쓴 동물
5종(토끼/호랑이/하마/사자/강아지)을 쓴다.** 두더지와 같은 470×548 캔버스·구멍 등장
방식. 둘의 구분은 **고글 착용 여부** (놀람/화남 포즈는 스팀·별·든 손 때문에 크기가
튀어 못 씀 → 고글로 구분).

### 다른 동물 (일반 얼굴)

두더지와 유사한 방식으로 출현. 그 동물이 있는 열을 강타하면:

* 목숨 -1
* 콤보 초기화
* 해당 영역 진행 없음

### 고글 낀 동물 (구 "폭탄")

그 동물이 있는 열을 강타하면:

* 제한시간 -3초
* 콤보 초기화
* 해당 영역 진행 없음
* (폭발 연출 삭제 — 이제 동물이라)

## 11. 목숨

기본 목숨은 3개다.

### 목숨 변화

두더지 성공:

* 목숨 변화 없음

동물이 있는 열 강타:

* ❤️ -1

폭탄:

* 목숨 변화 없음
* 시간 -3초

목숨이 0이 되면 실패한다.

## 12. 콤보

두더지를 연속으로 성공시키면 콤보가 증가한다.

| 콤보   |   점수 |
| ---- | ---: |
| 1    | +100 |
| 2    | +120 |
| 3    | +140 |
| 4    | +160 |
| 5 이상 | +200 |

5콤보 이상은 MAX COMBO 상태로 표시한다.

동물 또는 고글 동물이 있는 열을 강타하면 콤보를 0으로 초기화한다.

## 13. 영역 완성

두더지 성공 시 해당 영역이 즉시 완성된다.

연출:

두더지
→ 뿅망치
→ 타격
→ 두더지 제거
→ 해당 영역 이미지/색상 표시
→ 영역 완성 효과

완성된 영역은 다시 플레이 대상이 되지 않는다.

---

## 14. Emoji 완성

마지막 미완성 영역까지 성공하면 전체 Emoji 이미지가 완성된다.

최종 영역 성공 후 일반 영역 성공보다 강한 완성 연출을 적용한다.

연출:

마지막 두더지 성공
→ 뿅망치
→ 마지막 영역 완성
→ 전체 Emoji 완성
→ 반짝임/완성 효과
→ CLEAR 화면

---

## 15. 클리어 보상

클리어 시 다음 보상을 제공한다.

* ⭐ 별
* 🪙 코인
* 🖼️ 완성 Emoji 컬렉션 등록

별은 클리어 성적에 따라 1~3개를 지급한다.

## 16. 게임 난이도 상승 구조

두더지 게임의 난이도는 다음 요소를 동시에 상승시킨다.

1. 영역 수 증가
2. 동시 두더지 증가
3. 두더지 유지시간 감소
4. 방해물 증가
5. 방해물 종류 증가
6. 제한시간 감소

1단계는 게임 규칙을 익히는 단계로 구성하고,
10단계는 빠른 반응속도와 정확한 판단을 요구하는 고난도 단계로 구성한다.

---

## 17. 최종 게임 정체성

두더지 게임은 단순한 두더지 잡기가 아니라,

**"뿅망치로 두더지를 잡아 Emoji 그림을 완성하는 게임"**

을 핵심 정체성으로 한다.

어린이부터 성인까지 직관적으로 이해할 수 있어야 하며,
게임 조작은 단순하게 유지하고 난이도는 출현 패턴과 속도로 높인다.
